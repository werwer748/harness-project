# PRD: Shorts Idea Lab

## 목표
유튜브 쇼츠(일상생활 정보·명언·자기객관화) 제작자가 요즘 잘 되는 쇼츠를 근거로 다음에 만들 콘텐츠를 빠르게 정하게 한다.

## 사용자
위 세 주제로 한국어 쇼츠를 만드는 1인 크리에이터. 매번 직접 검색해서 트렌드를 감으로 판단하던 사람.

## 핵심 기능
1. **트렌드 수집**: 카테고리(생활 꿀팁 / 명언 / 자기객관화) 또는 직접 입력한 키워드로 최근 7·30·90일 인기 쇼츠(한국, 180초 이하)를 모은다
2. **분석**: 영상별 일평균 조회수·참여율, 자주 등장하는 키워드와 그 성과(기회 지수), 제목 패턴·영상 길이별 성과, 요약 수치를 보여준다
3. **다음 콘텐츠 추천**: 기회 지수가 높은 키워드마다 제목 후보 3개, 첫 3초 훅, 추천 근거, 참고 영상 3개를 담은 아이디어 카드를 만들고 localStorage에 저장할 수 있다

## MVP 제외 사항
- LLM 기반 생성 (추천은 규칙·템플릿 기반)
- 로그인, 서버 DB, 기기 간 동기화
- 영상 제작·업로드 자동화, 내 채널 연동(OAuth)
- 한국 외 지역·다국어

## 디자인

- 무채색 + 포인트 1색(amber)
